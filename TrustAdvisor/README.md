# Trust Advisor

Remember who you'd group with again: a fair, forgiving reputation for the people you play with in World of Warcraft: Forever, built from what the game actually saw, with every rule visible.

Type **/ta** in game to open it. On first login, a welcome screen lets you choose what, if anything, to share. Everything starts off.

- `/ta network`: the optional Trust Advisor Network and its companion app
- `/ta help`: every command

**Privacy:** chat text is never stored. Notes and private opinions never leave your computer. Nothing is shared unless you turn it on.

Companion app, source code and bug reports: https://github.com/viniciuscotrim/trust-advisor
